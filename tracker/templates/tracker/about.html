About

A simple Django task tracker with optional category grouping.

Purpose

This project helps users record tasks, view them on a dashboard, and track completion. Categories can be used to group tasks when helpful.

Planned Features

  • Create tasks with optional category and due date
  • View tasks on a dashboard
  • Mark tasks complete/incomplete
  • Improve usability and design over time
