How to use the template

1) Download the Excel template.

2) Open it and read the Instructions tab.

3) Fill in the Tasks tab (one task per row).

4) Upload the saved .xlsx file here.

Import behavior

• Tasks are imported into your account only.

• If a category name doesn’t exist yet, it will be created automatically.

• Category is optional — leaving it blank is okay.
